# 🍲 «Что приготовить» — Android-приложение (Kotlin)

Приложение подбирает блюда из продуктов, которые уже есть дома: вы отмечаете ингредиенты —
получаете список блюд с калорийностью и пошаговым способом приготовления.

---

## 1. Как открыть проект в Android Studio (3 шага)

1. Скачайте папку **`ChtoPrigotovit`** целиком (все файлы вместе с подпапками).
2. Android Studio → **File → Open** → выберите папку `ChtoPrigotovit` (не файл внутри, а саму папку) → **OK**.
3. Дождитесь **Gradle Sync** (первый раз скачивает зависимости, нужен интернет).
   Затем нажмите ▶ **Run 'app'** — приложение запустится на эмуляторе или телефоне.

Если Studio ругается на Gradle wrapper (в архиве нет `gradle-wrapper.jar` —
это нормально для текстового проекта), сделайте одно из двух:

* **File → Sync Project with Gradle Files** (значок слона 🐘 вверху справа) — Studio сама докачает wrapper;
* или **Settings → Build, Execution, Deployment → Build Tools → Gradle → Use Gradle from:**
  выберите `gradle-wrapper.properties file` (или `Local installation`, если Gradle 8.2+ установлен).
* JDK: **Settings → Build Tools → Gradle → Gradle JDK = 17** (Android Studio Koala и новее уже так настроены).

Версии: AGP 8.2.2, Kotlin 1.9.22, Gradle 8.2, compileSdk 34, minSdk 26.

---

## 2. Первый запуск

1. Открывается **окно входа** «Что приготовить?».
2. Нажмите «Нет аккаунта? Зарегистрироваться» → введите имя, e-mail и пароль (от 4 символов) →
   «Зарегистрироваться».
3. Дальше вход уже по e-mail + паролю. Аккаунты хранятся локально в SharedPreferences
   (интернет не нужен, никакого сервера).

Пример: `test@mail.ru` / `1234`.

## 3. Что умеет приложение

| Экран | Возможности |
|---|---|
| **Вход / Регистрация** (`LoginActivity`) | проверка e-mail, длины пароля, существующего аккаунта, показ ошибок |
| **Выбор продуктов** (`MainActivity`) | **115 ингредиентов** в 8 категориях, поиск по названию, мультивыбор «чипами», счётчик выбранного, очистка выбора, приветствие по имени, переход в профиль |
| **Список блюд** (`DishListActivity`) | **68 блюд**, сортировка «сначала то, что можно приготовить прямо сейчас», бейдж «Всё есть ✅» / «не хватает: N», калорийность, время, сложность |
| **Карточка блюда** (`DishDetailActivity`) | описание, ккал на 100 г и на порцию, время, сложность, категория, список продуктов с отметками ✓/✕ («нужно купить»), **пошаговый способ приготовления**, совет, добавление в избранное ⭐ |
| **Профиль** (`ProfileActivity`) | аватар с инициалом, изменение имени и e-mail, норма калорий в день, избранные блюда, выход из аккаунта, удаление аккаунта |

База блюд: завтраки, супы, салаты, горячее, гарниры, десерты, напитки —
от омлета и борща до карбонары, плова, шаурмы, брауни и лимонада.

## 5. Как добавить свои блюда

Откройте `app/src/main/java/com/chtohotovit/data/Dishes.kt` и добавьте в список `all` строку:

```kotlin
d(69, "Название блюда", "🍜", "Горячее", 180, 30, "Легко", 300,
    "Короткое описание.",
    listOf("Куриное филе", "Рис", "Соль"),        // названия должны быть из Ingredients.kt
    listOf("Первый шаг.", "Второй шаг."),
    "Совет (можно не писать)")
```

Ингредиенты добавляются в `Ingredients.kt` — просто новая строка
`Ingredient("Название", "🍏")` в нужной категории. Список подбора обновится автоматически.

## 6. Если что-то не собирается

* **Sync failed / не скачиваются зависимости** — проверьте интернет и
  *File → Settings → Build Tools → Gradle*, нажмите **Sync** повторно.
* **Unsupported Gradle version** — Studio предложит «Upgrade Gradle plugin»: согласитесь **Fix**.
* **minSdk 26** — приложение не запустится на Android ниже 8.0 (для более старых
  устройств поставьте `minSdk = 24` в `app/build.gradle.kts`, иконка-адаптив уже учтена).
* Пароли хранятся в открытом виде в SharedPreferences — это учебный проект,
  для продакшена нужен сервер и хеширование.
